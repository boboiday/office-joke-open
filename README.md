One single-line joke about office life, for the make.fun bounty "Make the AI Judge Laugh: the Office Joke Open".

> The Wi-Fi password changes every month, but the Post-it with the new one hasn't moved since 2023.

## Run it

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (one line, 97 characters, UTF-8). Deterministic: the same fixed line on every run, no randomness, no network, no clock.
